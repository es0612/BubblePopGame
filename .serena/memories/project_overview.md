# シャボン玉消しゲーム プロジェクト概要

## プロジェクト目的
SwiftUI、SwiftData、MVVMアーキテクチャを使用したモダンなiOSゲームアプリ。時間制限内でシャボン玉をタップして割るゲームプレイに加えて、数字順に消すモードなどの拡張機能も含む。

## 技術スタック
- **UI**: SwiftUI
- **データ永続化**: SwiftData
- **アーキテクチャ**: MVVM with @Observable macros
- **アニメーション**: Core Animation + SwiftUI
- **音響**: AVAudioEngine
- **テスト**: SwiftTesting framework
- **触覚フィードバック**: UIKit (UIImpactFeedbackGenerator)

## 主要な機能要件
- シャボン玉の表示とアニメーション（浮遊・跳ね返り）
- タップによるシャボン玉破裂とエフェクト
- 時間制限60秒とスコアシステム
- 数字順消しゲームモード（戦略的プレイ）
- BGMと効果音システム
- 設定画面（音量・振動調整）
- ハイスコア記録・表示
- レスポンシブデザイン対応
- アクセシビリティ対応

## 品質要件
- 60FPS維持のパフォーマンス
- 100ms以内のタッチ応答性
- 包括的なテストカバレッジ（SwiftTesting）
- メモリ効率化（オブジェクトプール）
