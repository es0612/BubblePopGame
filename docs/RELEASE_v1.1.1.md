# RELEASE v1.1.1 — 音の設定・チェーン・iPad 設定画面の不具合修正

- 対象: BubblePopGame v1.1.1 の App Store 提出
- 作成: 2026-10-18
- 関連: #66 / PR #72（音の設定）・#67 / PR #71（ノーマルモードのチェーン）・#68 / PR #73（iPad の設定画面）・#65（説明文と実装のずれ）
- 起点: 2026-10-18 のリポ監査（#65〜#70 を起票）

## 背景（なぜ v1.1.1 か）

v1.1 の承認後、`MARKETING_VERSION` を 1.1.1 に上げていました（#58 / PR #59、build 49 は 1.1.1 として受理済み）。ただ、v1.1 からのアプリの差分はバージョン番号だけで、出せる変更はありませんでした。そこで 2026-10-18 にリポを監査し、v1.0 から出荷中のコードにある、ユーザーが気づける不具合のうち次の 4 条件を満たすものを 1.1.1 に入れました。

- 呼び出し経路で確認済み
- ユニットテストで RED→GREEN を書ける（View 層は手動確認）
- PO の判断待ちがない
- スクショの撮り直しが設定画面だけで済む（iPad の設定画面は PO 判断で範囲に追加）

## このバージョンの内容

| 変更 | ユーザーから見た変化 | PR |
| --- | --- | --- |
| 音量スライダーの値をすぐに AudioService へ伝える | BGM 音量を変えると、その場で音量が変わる（これまでは再起動まで反映されなかった） | #72 |
| 効果音 OFF を AudioService の 1 箇所で判定する | 効果音を OFF にすると、メニュー・リザルト・ハイスコア・チュートリアルのボタン音も鳴らない | #72 |
| 設定リセットで音の設定も反映する | BGM を OFF にしてからリセットすると、BGM が鳴るようになる | #72 |
| BGM 再生の前に残っているフェードを止める | ゲームが終わった直後に「もう一度プレイ」を押しても BGM が止まらない | #72 |
| ノーマルモードの空振りでチェーンを切る | リザルトの「最大チェーン」が、割った数と別の値になる（スコアは 1 個 1 点のまま） | #71 |
| 設定画面の NavigationView の入れ子を外す | iPad で設定画面が全幅で表示される。iPhone でもタイトル下の空白がなくなる | #73 |

## What's New 下書き

ja と en のどちらも絵文字を使いません（ASC が ja/en とも絵文字を「無効な文字」として拒否するため）。

> ja:
> ・設定画面の音量スライダーが、すぐに反映されるようになりました
> ・効果音をオフにしたとき、ボタンの音も鳴らないようにしました
> ・ゲーム終了直後に「もう一度プレイ」を押すと BGM が止まる問題を直しました
> ・ノーマルモードで空振りするとチェーンが途切れるようにしました（最大チェーンが正しく表示されます）
> ・iPad で設定画面が狭く表示される問題を直しました

> en:
> - Volume sliders in Settings now take effect immediately.
> - Button sounds are now muted when sound effects are turned off.
> - Fixed BGM stopping when tapping Play Again right after a game ended.
> - In Normal mode, a missed tap now breaks your chain, so Max Chain is shown correctly.
> - Fixed the Settings screen appearing in a narrow column on iPad.
