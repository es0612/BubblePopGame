## 🎮 基本的な遊び方

### ゲーム開始方法
1. アプリを起動
2. メニュー画面で「ゲーム開始」をタップ
3. 画面に現れるシャボン玉をタップして消去
4. 制限時間内にできるだけ多くのスコアを獲得

### ゲームモード

#### 通常モード
- **目的**: 自由にシャボン玉を消してスコアを競う
- **操作**: 画面上の任意のシャボン玉をタップ
- **スコア**: 1個につき1ポイント
- **特徴**: リラックスして楽しめるモード

#### 数字順モード
- **目的**: 数字の順番通りにシャボン玉を消す
- **操作**: 1番から順番にタップ（間違えるとペナルティ）
- **スコア**: 正解時2ポイント、不正解時ペナルティ
- **特徴**: 集中力と判断力が要求されるチャレンジモード

## ⚙️ 設定方法

### 基本設定にアクセス
1. メニュー画面で「設定」をタップ
2. 各項目を調整
3. 「完了」をタップして保存

### ゲーム設定

#### ゲームモード選択
- **通常モード** / **数字順モード** から選択
- セグメントコントロールで切り替え

#### 制限時間設定
- **範囲**: 30秒〜180秒
- **調整**: ステッパーで15秒刻みで変更
- **初期値**: 30秒（じっくり遊ぶなら60〜90秒もおすすめ）

#### シャボン玉の数
- **範囲**: 10個〜50個
- **調整**: ステッパーで5個刻みで変更
- **推奨**: 初心者は20個、上級者は30個以上

### 音響設定

#### BGM設定
- **ON/OFF**: トグルスイッチで切り替え
- **楽曲選択**: 3つのトラックから選択
  - トラック1: 穏やかなメロディ
  - トラック2: 活発なリズム
  - トラック3: 幻想的なサウンド
- **音量調整**: スライダーで0〜100%

#### 効果音設定
- **ON/OFF**: トグルスイッチで切り替え
- **音量調整**: スライダーで0〜100%
- **種類**: シャボン玉破裂音、ボタンタップ音

### システム設定

#### バイブレーション
- **ON/OFF**: トグルスイッチで切り替え
- **対応操作**: シャボン玉タップ時、ボタン押下時
- **注意**: デバイスがサイレントモードでも動作

#### 設定リセット
- **機能**: 全設定をデフォルト値に戻す
- **注意**: 操作は取り消せません
- **対象**: ゲーム設定、音響設定、システム設定

## 🔧 トラブルシューティング

### よくある問題と解決方法

#### Q1: アプリが起動しない
**解決方法**:
1. デバイスを再起動
2. アプリを完全に終了してから再起動
3. iOS バージョンを確認（17.0以降が必要）
4. ストレージ容量を確認（50MB以上推奨）

#### Q2: 音が出ない
**解決方法**:
1. デバイスの音量を確認
2. サイレントモードを解除
3. アプリ設定で効果音・BGMがONになっているか確認
4. 他のアプリで音が出るか確認

#### Q3: 動作が重い・カクつく
**解決方法**:
1. 他のアプリを終了してメモリを確保
2. デバイスを再起動
3. シャボン玉の数を減らす（設定→シャボン玉の数）
4. 古いデバイスの場合は制限時間を長めに設定

#### Q4: タッチが反応しない
**解決方法**:
1. 画面が清潔か確認
2. 手が乾燥していないか確認
3. 画面保護フィルムの状態を確認
4. アプリを再起動

#### Q5: スコアが保存されない
**解決方法**:
1. ゲーム終了まで正常にプレイ
2. ゲーム終了画面で「メニューに戻る」をタップ
3. ストレージ容量を確認
4. アプリの再インストール（最終手段）

#### Q6: 設定が保存されない
**解決方法**:
1. 設定変更後「完了」ボタンをタップ
2. アプリを一度終了してから再起動
3. iOSの設定でアプリの権限を確認

## 🎮 How to Play

### Starting the Game
1. Launch the app
2. Tap "Start Game" on the menu screen
3. Tap soap bubbles that appear on the screen to pop them
4. Get as many points as possible within the time limit

### Game Modes

#### Normal Mode
- **Objective**: Freely pop bubbles and compete for scores
- **Controls**: Tap any bubble on the screen
- **Scoring**: 1 point per bubble
- **Features**: Relaxing mode for enjoyment

#### Numbered Mode
- **Objective**: Pop numbered bubbles in sequential order
- **Controls**: Tap from number 1 in order (penalty for mistakes)
- **Scoring**: 2 points for correct, penalty for incorrect
- **Features**: Challenge mode requiring concentration and judgment

## ⚙️ Settings Configuration

### Accessing Settings
1. Tap "Settings" on the menu screen
2. Adjust each item
3. Tap "Done" to save

### Game Settings

#### Game Mode Selection
- Choose between **Normal Mode** / **Numbered Mode**
- Switch using segment control

#### Time Limit Settings
- **Range**: 30-180 seconds
- **Adjustment**: Change in 15-second increments using stepper
- **Recommended**: 60 seconds for beginners, 30 seconds for advanced

#### Number of Bubbles
- **Range**: 10-50 bubbles
- **Adjustment**: Change in 5-bubble increments using stepper
- **Recommended**: 20 for beginners, 30+ for advanced

### Audio Settings

#### BGM Settings
- **ON/OFF**: Toggle with switch
- **Music Selection**: Choose from 3 tracks
  - Track 1: Gentle melody
  - Track 2: Lively rhythm
  - Track 3: Ethereal sound
- **Volume**: Adjust with slider 0-100%

#### Sound Effects Settings
- **ON/OFF**: Toggle with switch
- **Volume**: Adjust with slider 0-100%
- **Types**: Bubble pop sound, button tap sound

### System Settings

#### Vibration
- **ON/OFF**: Toggle with switch
- **Supported Actions**: Bubble tap, button press
- **Note**: Works even in device silent mode

#### Settings Reset
- **Function**: Reset all settings to default values
- **Warning**: Action cannot be undone
- **Scope**: Game settings, audio settings, system settings

## 🔧 Troubleshooting

### Common Issues and Solutions

#### Q1: App won't start
**Solutions**:
1. Restart device
2. Force quit app and restart
3. Check iOS version (17.0+ required)
4. Check storage capacity (50MB+ recommended)

#### Q2: No sound
**Solutions**:
1. Check device volume
2. Turn off silent mode
3. Verify sound effects/BGM are ON in app settings
4. Test if other apps produce sound

#### Q3: Slow performance/lag
**Solutions**:
1. Close other apps to free memory
2. Restart device
3. Reduce number of bubbles (Settings → Bubble Count)
4. For older devices, set longer time limits

#### Q4: Touch not responding
**Solutions**:
1. Check if screen is clean
2. Check if hands are dry
3. Check screen protector condition
4. Restart app

#### Q5: Scores not saving
**Solutions**:
1. Play through to game completion
2. Tap "Back to Menu" on game over screen
3. Check storage capacity
4. Reinstall app (last resort)

#### Q6: Settings not saving
**Solutions**:
1. Tap "Done" after changing settings
2. Force quit and restart app
3. Check app permissions in iOS settings
