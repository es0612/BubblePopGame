## 日本語版

### プライバシーポリシー

当アプリ「シャボン玉消しゲーム」（以下「本アプリ」）は、ユーザーのプライバシーを最重要視し、個人情報の保護に関して細心の注意を払っています。本プライバシーポリシーは、本アプリにおけるユーザー情報の取り扱いについて説明するものです。

#### 1. 情報の収集

**本アプリは、ユーザーの個人情報を一切収集いたしません。**

具体的には、以下の情報は収集されません：
- 氏名、住所、電話番号、メールアドレス等の個人識別情報
- デバイス固有の識別情報（UDID、広告ID等）
- 位置情報
- 連絡先情報
- 写真や動画
- その他一切の個人情報

#### 2. データの保存

本アプリで生成・保存されるデータは以下のとおりです：

**ローカル保存データ（デバイス内のみ）**
- ゲームスコア記録
- ゲーム設定（音量、BGM選択、振動設定等）
- ゲーム統計情報（プレイ回数、最高スコア等）

これらのデータは全て：
- ユーザーのデバイス内にのみ保存
- 外部サーバーへの送信は一切なし
- Apple標準のSwiftDataフレームワークを使用
- iOSのサンドボックス内で安全に管理

#### 3. データの共有

**本アプリは、いかなるデータも第三者と共有いたしません。**

- 広告ネットワークとの連携なし
- 分析ツールとの連携なし
- SNS連携機能なし
- クラウド同期機能なし

#### 4. データの削除

ユーザーは以下の方法でデータを削除できます：

- **設定リセット**: アプリ内設定画面から「設定をリセット」を実行
- **アプリ削除**: デバイスからアプリを削除することで全データが削除

データ削除後の復旧は不可能です。重要なスコア記録がある場合はご注意ください。

#### 5. アクセシビリティ機能

本アプリはアクセシビリティ向上のため、以下のiOS標準機能を使用します：

- VoiceOver（画面読み上げ機能）
- Dynamic Type（文字サイズ調整）
- 高コントラスト表示

これらの機能使用時も、個人情報の収集や外部送信は一切行いません。

#### 6. 音響・触覚フィードバック

本アプリの音響・触覚フィードバック機能：

- **BGM・効果音**: アプリ内蔵音源のみ使用
- **振動フィードバック**: iOS標準のUIImpactFeedbackGeneratorを使用
- **マイクアクセス**: 不使用
- **音声録音**: 不使用

#### 7. 広告・課金

本アプリには以下の要素は含まれません：

- 広告表示機能
- アプリ内購入機能
- 有料コンテンツ
- サブスクリプション機能

#### 8. 児童のプライバシー

本アプリは4歳以上の全年齢を対象としており、13歳未満の児童からも個人情報を収集いたしません。保護者の方も安心してお子様にご利用いただけます。

#### 9. セキュリティ

データセキュリティについて：

- 全データはデバイス内のみで処理
- iOS標準のサンドボックス内で隔離
- ネットワーク通信なし（初回のApp Store ダウンロード後）
- 暗号化はiOSの標準機能に依存

#### 10. プライバシーポリシーの変更

本プライバシーポリシーを変更する場合は：

- アプリアップデート時に新しいポリシーを明示
- 重要な変更がある場合は事前通知
- 常に最新版をアプリ内で確認可能

#### 11. お問い合わせ

プライバシーに関するご質問やご懸念がございましたら、App Store のアプリページからお問い合わせください。

#### 12. 適用法令

本プライバシーポリシーは、日本国の個人情報保護法および関連法令に準拠しています。

## English Version

### Privacy Policy

This privacy policy applies to the "Bubble Pop Game" app (hereinafter referred to as "the App") and explains how we handle user information. We prioritize user privacy and take utmost care in protecting personal information.

#### 1. Information Collection

**The App does not collect any personal information from users.**

Specifically, the following information is NOT collected:
- Personal identification information (name, address, phone number, email address, etc.)
- Device-specific identification information (UDID, advertising ID, etc.)
- Location information
- Contact information
- Photos or videos
- Any other personal information

#### 2. Data Storage

The App generates and stores the following data:

**Local Storage Data (Device Only)**
- Game score records
- Game settings (volume, BGM selection, vibration settings, etc.)
- Game statistics (play count, high scores, etc.)

All this data is:
- Stored only on the user's device
- Never transmitted to external servers
- Managed using Apple's standard SwiftData framework
- Securely handled within iOS sandbox

#### 3. Data Sharing

**The App does not share any data with third parties.**

- No advertising network integration
- No analytics tool integration
- No social media integration features
- No cloud synchronization features

#### 4. Data Deletion

Users can delete data through the following methods:

- **Settings Reset**: Execute "Reset Settings" from the in-app settings screen
- **App Deletion**: Delete the app from the device to remove all data

Data recovery after deletion is impossible. Please be cautious if you have important score records.

#### 5. Accessibility Features

The App uses the following iOS standard features to improve accessibility:

- VoiceOver (screen reading function)
- Dynamic Type (text size adjustment)
- High contrast display

Even when using these features, no personal information is collected or transmitted externally.

#### 6. Audio & Haptic Feedback

The App's audio and haptic feedback features:

- **BGM & Sound Effects**: Uses only built-in app audio sources
- **Vibration Feedback**: Uses iOS standard UIImpactFeedbackGenerator
- **Microphone Access**: Not used
- **Audio Recording**: Not used

#### 7. Advertising & Purchases

The App does not include:

- Advertising display functionality
- In-app purchase functionality
- Paid content
- Subscription functionality

#### 8. Children's Privacy

The App is designed for ages 4+ and does not collect personal information from children under 13. Parents can confidently allow their children to use the app.

#### 9. Security

Regarding data security:

- All data is processed only on the device
- Isolated within iOS standard sandbox
- No network communication (after initial App Store download)
- Encryption relies on iOS standard functionality

#### 10. Privacy Policy Changes

When changing this privacy policy:

- New policy will be clearly indicated during app updates
- Prior notification for significant changes
- Latest version always available within the app

#### 11. Contact

For questions or concerns regarding privacy, please contact us through the App Store app page.

#### 12. Applicable Laws

This privacy policy complies with Japan's Personal Information Protection Act and related laws, as well as international privacy standards.
